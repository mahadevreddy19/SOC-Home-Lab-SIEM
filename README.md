# SOC Home Lab – SIEM Based Threat Detection & Incident Response

## Overview
This repository documents a personal SOC learning project focused on
log analysis, alert triage, and incident response using SIEM tools.

## Objectives
- Understand SOC workflows and alert investigation
- Analyze logs and detect malicious activity
- Practice incident response lifecycle
- Map activity to MITRE ATT&CK

## Tools Used
- SIEM: Splunk / Elastic
- Logs: Windows Event Logs, Sysmon
- Network Analysis: Wireshark
- Platform: TryHackMe SOC Simulator

## Skills Demonstrated
- Alert triage and investigation
- SIEM log analysis
- Incident response workflow
- MITRE ATT&CK mapping

## Disclaimer
All activities were performed in a controlled learning environment.
